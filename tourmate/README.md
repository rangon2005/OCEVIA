# TourMate

Offline chat for travellers who are near each other. Needs only Node.js, no internet and no packages.

1. Run `node tourmate-server.js` on a laptop, or on Android with Termux.
2. Turn on that device's Wi-Fi hotspot (or use one shared Wi-Fi router).
3. Others join the hotspot and open the address printed in the terminal.
   If none is printed, find the hotspot device's IP in its settings and open `http://IP:3000`.

Messages are not encrypted and are not stored. Use a hotspot password.
